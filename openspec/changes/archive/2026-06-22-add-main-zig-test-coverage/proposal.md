## Why

`src/main.zig` currently has no direct unit or behavioral test coverage for the core `rot` and `xorot` logic. That leaves boundary behavior, streaming semantics, and byte-level invariants unprotected during future refactors or Zig stdlib migrations.

## What Changes

- Add automated test coverage for the `rot` byte transformation across alphabetic, numeric, and passthrough boundary cases.
- Add automated test coverage for `xorot` stream processing, including empty input, deterministic known vectors, multi-chunk processing, and `u8` index wraparound behavior.
- Add randomized and property-oriented tests that exercise binary inputs and verify key invariants against a reference formulation of the transform.
- Add a fuzz-oriented test path suitable for repeatedly stressing the transform with generated byte streams during development and CI-compatible test runs.

## Capabilities

### New Capabilities
- `xorot-test-coverage`: Defines required automated test coverage and invariants for the `xorot` byte transformation and stream-processing behavior.

### Modified Capabilities
- None.

## Impact

- Affected code: `src/main.zig`, `build.zig`, and any new test-only helpers or fixtures needed for Zig tests.
- Affected systems: local developer test workflow and CI test execution.
- Dependencies: Zig standard test tooling only unless a lightweight fuzz/property approach is added without external runtime dependencies.
